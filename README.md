# 烷烃四关通关游戏 V2.3 GitHub Pages 上传说明

这个压缩包用于把游戏发布成网页。学生用电脑点击网址，或用安卓、苹果手机扫描该网址的二维码，在浏览器里完成同一套四关游戏。**不要把 ZIP 或 HEP5 文件的下载地址做成二维码。**

## 一、上传到 GitHub

1. 登录 GitHub，新建一个 **Public** 仓库，例如 `alkane-four-game`。不要把真实学生名单、成绩或账号密码放进仓库。
2. **先解压本 ZIP**。把解压后文件夹内的 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标文件、`.nojekyll` 和 `README.md` 上传到仓库的**顶层**，不要只上传 ZIP，也不要多套一层 `alkane-github-pages-v2-3` 文件夹。发布根目录中必须直接看见 `index.html`。
3. 打开仓库 `Settings → Pages`，在 `Build and deployment` 中选择 `Deploy from a branch`，选择 `main` 分支和 `/(root)`，点击 `Save`。
4. 等待部署完成，点击 Pages 设置页的 `Visit site`，**复制页面显示的实际网址**。普通项目仓库的网址通常是 `https://用户名.github.io/仓库名/`，请以 Pages 页面给出的地址为准。
5. 用电脑、安卓 Chrome、苹果 Safari 各打开一次实际网址。确认能进入身份页、完成第一题、关闭后重开还能恢复进度。再用实际网址生成二维码，贴到智慧职教作业说明里，并同时放一个可点击的网址。

如果第 4 步显示 404：检查 `index.html` 是否在仓库根目录、Pages 是否选了 `main / (root)`，并等待部署完成。若学校 Wi-Fi 打不开，再用手机流量测试；若两种网络都打不开，需要学校提供可访问的校内网页空间或域名，不能靠更换二维码解决。

## 二、包内文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 游戏页面；CSS 和游戏逻辑均在这一文件中 |
| `service-worker.js` | 首次在线加载后的可选离线缓存 |
| `manifest.webmanifest` | 手机添加到主屏幕的应用信息 |
| `icon.svg`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png` | 浏览器与手机桌面图标 |
| `.nojekyll` | 告诉 GitHub Pages 直接发布这些静态文件 |
| `README.md` | 本说明 |

游戏页面不依赖外部脚本或字体；图标、离线缓存和安装提示属于增强功能。浏览器不能安装到主屏幕时，仍可在线完成游戏。

## 三、成绩与隐私边界

- 身份、答题记录和成绩默认只保存在**当前设备的当前浏览器**。换浏览器、换手机或清除网站数据后不能自动找回。建议学生始终从同一浏览器打开；微信等内置浏览器若存档不稳定，应改用 Chrome 或 Safari。
- 游戏端通关后锁定页面中的正式答案、生成一页成绩单和本机核验码。但 GitHub Pages 只是静态托管，**不会自动把成绩写进智慧职教**；设备持有人仍可能通过技术手段修改本机数据或网页程序，因此本机成绩单不能当作不可篡改的正式成绩。
- 如果要在智慧职教统一统计且由学生端无法修改，必须另接学校服务器或平台官方成绩回传接口，由服务器确认身份、记录和分数。在接口接通前，请用智慧职教原生作业题作为正式计分依据。
- GitHub Pages 网页通常公开。不要把包含学号和姓名的成绩单、名单、密钥或成绩数据库提交到仓库。

## 四、二维码

本包**未放入二维码**，因为仓库尚未发布，真实网址还没有确定。发布后把 `Visit site` 给出的完整 HTTPS 网址发来，再按该网址生成二维码。二维码应指向网页首页，不是 `github.com/…/blob/…/index.html`、ZIP、HEP5 或原始文件下载链接。
