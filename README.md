# 烷烃四关通关游戏 V2.14 · 逐步作答与学习记录版

## 更新原 GitHub Pages

1. 解压 ZIP，将其中的 **9 个文件**全部上传到原仓库顶层，覆盖同名文件；不要把 ZIP 文件本身当作网页上传。顶层必须有 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明。
2. 等待仓库 `Settings → Pages` 部署完成。用原网址打开并刷新，确认页面顶部显示 **V2.14**。原网址和二维码不变。
3. 学生应在原设备、原浏览器继续；首次更新后如果仍看见 V2.13，可重新打开页面或强制刷新。不要清除网站数据，因为进度保存在浏览器里。

独立的 `烷烃四关通关游戏_V2.14.html` 可以直接离线打开；GitHub Pages 推荐使用 ZIP 内 `index.html`。不要上传学生身份、学号或导出的学习记录到公开仓库。

## 本次修复：第 4 关 · 2 / 3

旧版把“查看第一步 → 选择反应能否继续”作为学生可见步骤，但点击结论时会清掉一个隐藏的“依据”字段；提交又要求该字段，导致反复显示“还有 1 处证据尚未填写”，正式尝试却一直是 0。V2.14 只检查本题页面可见的结论；查看第一步后选完结论即可提交。第 1、3 题仍按各自可见的字段判定。

V2.13 的同设备同浏览器记录会连同已选结论和详细学习事件一起迁移。若原先已查看第一步并选好结论，更新后可直接提交；若观察尚未保存，先点“查看第一步”。此前被误拦截的提交不补算为正式错误或正式尝试。原始 V2.13 存档仍保留，勿清理网站数据。

## 四关的交互顺序

| 关卡 | 学生看到的步骤 |
| --- | --- |
| 1 命名侦探 | 找最长主链 → 选编号方向 → 定甲基位次 → 数甲基 → 输入名称 → 提交。 |
| 2 结构简式工厂 | 筛选结构并显式确认 → 判断名称对应卡片；或先选主链 → 加甲基 → 检查碳四价与分子式 → 提交。候选卡片不再只给正确子集。 |
| 3 异构体工坊 | 筛选候选 → 找重复画法 → 归类骨架、说明依据与数量 → 收入图鉴。 |
| 4 氯代实验室 | 按题目先查看或运行观察，再填写页面可见的结论/依据 → 提交。第 2 题只选结论；第 3 题 A/B 运行先后均可，改一组条件只需重跑该组。保持前两题的适中难度。 |

只显示当前可作答步骤；按钮会提示下一步。未填完或缺少实验观察时，提交不可用，也不增加正式尝试。一次完整错误提交只记录一次正式尝试，不扣分；系统标出冲突字段并给线索。每关正式任务全部通过后，曾答错的小题必须在本关完成独立变式；练习尝试不更改正式分数、正式答案或完成时间。最后一关即使显示 100 分，错题未练完仍不开放报告或打印。

## 学生导出与教师统计

学生点击顶部“导出详细记录”，优先选“下载 Excel 可打开的详细 CSV”，把文件私下发送给老师；若手机不方便下载，可点“复制学习记录（手机转发）”，粘贴发送 JSON。网页不会自动上传。请勿把记录公开发布。

CSV 保持 **20 列**，每名学生导出为同一随机记录编号：任务汇总行包含正式/变式尝试、错题掌握、提示次数、漏填与阻断次数；逐次事件行按 `#事件序号` 排列，包含选择字段与选项代码、A/B组条件与运行、提示级别、提交结果、具体错误字段以及全局和本题活动秒数。根据“事件序号/正式尝试”“操作值/实验条件”两列可还原关键操作顺序。V2.12 及更早的旧记录不可能补回当时未采集的选择过程，升级后才开始记录新操作；历史提交和实验运行记录仍保留。事件总数超过 3000 时，导出说明会标明较早事件已截断。

导出不含姓名、学号、文字输入的完整名称或精确操作时间；但班级、选项轨迹与随机编号仍可能间接识别学生。重复导出沿用同一编号，适合把“进行中”和“通关后”的记录对齐；不要仅凭高频点击断定学生用了机器。V2.13 与 V2.14 均为同一套 20 列标题；合并更早数据时按版本检查列标题。

## 进度与成绩口径

V2.4—V2.13 的同设备同浏览器进度和锁定成绩可迁移；旧存档保留。V2.14 存档键为 `alkane-four-v2_14`，结构修订号为 16。已锁定的旧版成绩继续保留原版本号和本机核验码；V2.13 未完成题从已保存的选择继续，详细事件保留。更早版本的未完成实验题可能需要按简化流程重新设置本题条件。新记录的详细覆盖范围为 `full-v2.14`，V2.13 迁移为 `from-v2.13`，其余按来源版本标记。

成绩单只在四关及全部必修错题完成后开放。页面可见且学习进行中的时间计入活动用时；离线或切到后台的时间不计。客户端存档与本机核验码只能用于课堂过程反馈，不能承担正式考试的防篡改与统一收分；若学校需要自动收集，需另外接入受控的服务端。
