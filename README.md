# 烷烃四关通关游戏 V2.10 · 产物数量复核聚焦版

## 上传到原 GitHub Pages 仓库

1. 解压 ZIP，把其中 **9 个文件**全部上传到原仓库顶层，覆盖同名文件。顶层直接包含 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明。
2. 等待 `Settings → Pages` 部署完成。用原网址打开，确认页面显示 **V2.10**；网址不变，原二维码仍可使用。
3. 学生沿用原设备和浏览器重新打开并刷新；旧离线缓存更新后显示新版。

独立 HTML 可直接离线打开；GitHub Pages 请上传 ZIP 内全部文件。不要把学生名单、学号或导出的学习记录上传到公开仓库。

## V2.10 修改

第四关第 3 题“产物数量复核”的正式题和变式重练均把 A、B 两组受光条件固定为“光照”。页面以只读状态显示共同受光条件，学生只选择两组的氯气用量；两组用量必须不同，运行观察后再提交结论与依据。题目聚焦“氯气用量增加是否可能继续取代”，不再让已经学过的受光条件成为额外操作干扰。

第 1 题仍由学生自己设计受光条件对照；第 2 题继续判断一步反应式的适用边界。第 3 题的化学结论和评分标准没有改变。

## 进度、记录与成绩

V2.4—V2.9 的同设备同浏览器进度及已锁定成绩可迁移，旧存档保留。升级时，第 3 题未完成的实验会保留已选氯气用量，把受光条件统一设为光照，并清除与旧受光条件绑定的待运行快照；已完成任务和已锁定成绩不变。错题仍需在每关关尾完成变式重练，完成前不能打印成绩单。原随机记录编号沿用；新记录的详细覆盖范围为 `full-v2.10`，升级自 V2.9 的记录为 `from-v2.9`，此前已采集的事件保留。

学生可在进行中或通关后导出匿名学习记录；CSV 保持 20 列，不自动上传到 GitHub Pages。班级和学习轨迹仍可能间接识别个人，记录请定向发送给教师。客户端成绩锁仅防一般误改，不是服务器认证。
