# 烷烃四关通关游戏 V2.6 · 详细学习记录版

## 发布到原 GitHub Pages 地址

1. 解压 ZIP，把其中 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明文件共 9 个文件上传到原仓库顶层，覆盖同名文件。仓库根目录必须直接看见 `index.html`。
2. 等待 `Settings → Pages` 显示部署完成，从 Pages 页面打开实际网址，确认标题出现 **V2.6**。原仓库地址不变时，原二维码继续使用。
3. 在手机和电脑各试一次“复制详细记录”和“下载详细 CSV”。若仍显示旧版，关闭页面后重新打开并刷新；联网后离线缓存会更新为 V2.6。

独立 HTML 可直接离线打开。发布到 GitHub Pages 时应使用完整 ZIP 中的 9 个文件，以保留图标、安装提示和离线缓存。不要把学生记录、名单或学号上传到公开仓库。

## V2.6 具体记录什么

除原有每题正式尝试、曾答错、变式尝试和掌握状态外，V2.6 新增：

- 每次提交属于正式题还是变式题，是正确、错误、漏填还是因缺少实验运行/单变量对照被阻止；
- 错误落在哪个认知环节，例如最长主链、编号方向、甲基位次、系统名称、结构筛选、骨架归类、异构依据、实验条件、实验结论或证据依据；
- 每次提示的使用与提示层级；
- 每次实验运行的条件，以及当时是否已经形成题目要求的对照；
- 每道题累计的页面活动时间，以及事件发生时的整局活动秒数；
- 学生选填的“最难部分”。

记录不包含姓名、学号、训练编号、完整作答内容、精确时刻或 IP。网页不会自动上传，学生仍需主动把复制文本或 CSV 文件发给老师。班级和细分学习轨迹可能间接识别个人，应定向收集，不公开转发。

## 学生操作

1. 用原网址、原设备和原浏览器打开 V2.6。V2.4 或 V2.5 的本机进度与已通关成绩会复制到 V2.6，旧存档继续保留。
2. 正常完成游戏；进行中或通关后都可以点页面顶部的“导出详细记录”。
3. 可选填“最难的部分”，然后优先点“复制详细记录”粘贴发给老师；也可下载 CSV 后把文件发给老师。手机限制自动复制时，页面会出现可手动全选的文本。
4. 同一局沿用同一随机编号，教师可按编号合并多次导出，以最后一份为准。

旧版迁移只能保留旧版已有的汇总数据；逐次错误、提示、实验运行和分题时间从首次进入 V2.6 后开始记录。导出的 `详细覆盖范围` 会标明 `full-v2.6`、`from-v2.5` 或 `from-v2.4`，分析时不得把迁移前缺失的逐次事件当成“没有发生”。

## 教师分析说明

- 详细 CSV 恰好 **20 列**，符合不超过 20 列的导入限制；一名学生先有 14 行“任务汇总”，其后为若干行“逐次事件”。
- 汇总人数、总分和总用时时，先按随机记录编号去重；逐题分析时按“任务编号”分组；认知卡点按“错误或阻断项”统计。
- 可重点区分：知识错误、漏填、修改条件后未重新运行、没有形成单变量对照、查看提示后仍答错、正式题通过但变式题未掌握。
- 本地数据适合改进教学与游戏反馈，不是防篡改考试凭证。活动时间只累计页面可见且处于任务或变式题的学习时段；分题时间不包含通关页、成绩单或后台停留。
