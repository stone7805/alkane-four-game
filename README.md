# 烷烃四关通关游戏 V2.8 · 提交按钮修复版

## 更新到原 GitHub Pages 地址

1. 解压 ZIP，将其中 **9 个文件**全部上传到原仓库顶层，覆盖同名文件。顶层直接包含 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明。
2. 等待 `Settings → Pages` 部署完成。用原网址打开，确认页面显示 **V2.8**；网址不变，二维码仍可使用。
3. 学生最好沿用原设备和原浏览器，联网重新打开并刷新。旧离线缓存更新后会显示 V2.8。

独立 HTML 可直接离线打开；GitHub Pages 请上传 ZIP 内所有文件。不要把学生名单、学号或导出的学习记录上传到公开仓库。

## V2.8 修复内容

- 从旧进度直接进入未完成的氯代实验时，提交按钮始终显示。证据尚未齐全时按钮呈禁用状态，并在按钮上方直接说明还差哪一步，不再把按钮整个隐藏。
- 两组实验形成有效对照后，结论与依据立即开放，提交按钮同步启用，并自动把页面带到结论区域。观察记录移动到操作按钮之后，手机上不必翻过很长的日志才能找到提交入口。
- 若 A、B 两组没有形成有效对照，页面会明确指出应固定哪一项、改变哪一项；修正某一组后只需重新运行该组。
- 修复漏填答案时对应选项区域不能正确标出的字段定位问题。

## 保留的学习流程

- 每关正式题做完后，如有答错的档案，先在**本关**完成变式重练，再进入下一关。地图上“已掌握”表示本关正式题和错题重练均完成；未重练显示“待重练”。分数显示正式掌握分，错题未练不能打印成绩单。
- 氯代实验第 1 和第 3 档案先分别设置 **A 组、B 组**的受光条件与氯气用量，运行两组并查看观察，再选结论与依据。第 2 档案先运行一组，再解释一步反应式。更改某组条件只需重新运行这一组；修改结论不必重做实验。
- 第 1 档案接受“遮光/氯气过量”和“光照/氯气过量”这类有效的单变量受光对照；第 3 档案需要在两组有光引发氯代现象的条件下比较氯气用量。两组选择不会互相覆盖。
- 与上次完全相同的错误答案重复提交会提示先修改冲突项，不增加正式尝试次数。

## 本机进度与导出

V2.4—V2.7 的本机进度和已有成绩单可迁移，旧存档仍保留。已经通过的正式题不会重新要求作答；未完成或尚待重练的任务从相应关卡继续。旧版成绩锁与匿名随机编号保留。不要在不同设备或浏览器之间期待自动同步。

学生可在进行中或通关后点击“复制详细记录”或“下载 Excel 可打开的详细 CSV”，定向发给老师。CSV **恰好 20 列**，包含 14 行任务汇总及逐次事件；新增实验运行的 `A组` / `B组` 标记，仍用原“实验条件”列。重复导出沿用同一随机编号。记录不包含姓名、学号、完整答案、精确时间或 IP；班级与学习轨迹仍可能间接识别个人，不要公开转发。

教师分析时按随机编号去重，按任务编号和错误项比较；将“漏填/对照未形成/重复未修改”与实际知识错误分开。旧版迁移前没有采集的逐次事件不可当作零次；`详细覆盖范围` 会标明 `full-v2.8` 或来源版本。

本机记录适合改进教学，不是服务器确认的考试成绩。活动用时只累计网页可见的学习时段；已通关成绩锁定且一页打印。GitHub Pages 不自动收集学生数据。
