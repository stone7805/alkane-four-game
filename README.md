# 烷烃四关通关游戏 V2.12 · 对照实验引导版

## 上传到原 GitHub Pages 仓库

1. 解压 ZIP，把其中 **9 个文件**全部上传到原仓库顶层，覆盖同名文件。顶层直接包含 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明。
2. 等待 `Settings → Pages` 部署完成。用原网址打开，确认页面显示 **V2.12**；网址不变，原二维码仍可使用。
3. 学生沿用原设备和浏览器重新打开并刷新；旧离线缓存更新后显示新版。

独立 HTML 可直接离线打开；GitHub Pages 请上传 ZIP 内全部文件。不要把学生名单、学号或导出的学习记录上传到公开仓库。

## V2.12 修改

第四关第 1 题由“学生独立设置 A、B 两组的光照与氯气用量”改为引导式单变量对照。A组的遮光条件、氯气用量和观察结果直接给出；A、B两组的氯气用量由系统固定相同。学生只需为B组选择受光条件、查看结果，再回答一道二选一问题：“哪项条件能解释两组差异？”

如果B组仍选择遮光，页面说明“A、B两组都是遮光，观察相同”，允许改选并重新查看，且不计正式作答次数。形成有效对照后，只显示“受光条件不同”和“氯气用量不同”两个答案；结论字段由系统根据观察补全，不再要求学生同时提交“结论 + 依据”。第 2 题和第 3 题的 V2.11 简化逻辑保持不变。

## 进度、记录与成绩

V2.4—V2.11 的同设备同浏览器进度及已锁定成绩可迁移，旧存档保留。升级时，第 1 题未完成的正式答题或待做变式会重新进入新版引导流程；已完成任务和已锁定成绩不变。错题仍需在每关关尾完成变式重练，完成前不能打印成绩单。原随机记录编号沿用；新记录的详细覆盖范围为 `full-v2.12`，升级自 V2.11 的记录为 `from-v2.11`，此前已采集的事件保留。

学生可在进行中或通关后导出匿名学习记录；CSV 保持 20 列，不自动上传到 GitHub Pages。班级和学习轨迹仍可能间接识别个人，记录请定向发送给教师。客户端成绩锁仅防一般误改，不是服务器认证。
