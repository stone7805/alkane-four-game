# 烷烃四关通关游戏 V2.5 · 发布和学习记录说明

## 发布到原 GitHub Pages 地址

1. 解压 ZIP，打开其中的文件夹；把 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明文件一起上传到原仓库的**顶层**。用新版文件覆盖同名文件，仓库根目录须直接看见 `index.html`。不要上传压缩包本身，也不要多套一层文件夹。
2. 等待仓库 `Settings → Pages` 显示本次部署完成，再从 Pages 页面打开实际网址，核对标题出现 **V2.5**。原仓库地址不变时，原二维码通常可以继续使用。
3. 用手机和电脑各打开一次，试点“复制学习记录”“下载 Excel 可打开的 CSV”。如果仍显示旧版，关闭页面后重新打开，必要时刷新页面；离线模式会在联网更新后切换到新的缓存版本。

仅上传独立的 `烷烃四关通关游戏_V2.5.html` 也能在浏览器玩和导出；要在 GitHub Pages 仓库根网址下使用，请上传本包的 `index.html`。其余文件用于图标、安装和离线缓存。不要把学生记录、姓名名单或学号上传到公开仓库。

## 学生操作

1. 在手机或电脑**同一个浏览器、同一个原网址**打开 V2.5。已有 V2.4 本机进度或成绩会在首次打开时复制到新版存档；旧版记录仍保留。页面若提示恢复失败，请保留原设备数据，先不要开始新训练。
2. 在任意学习进度，滚动到“把学习记录发给老师”。可选填“最难的部分”，不填也能导出，不影响成绩。
3. 优先点 **复制学习记录**，将复制到的 JSON 文本粘贴发给老师；或点 **下载 Excel 可打开的 CSV**，把下载的文件发送给老师。手机禁止自动复制时，页面会显示可手动全选的文本。
4. 同一局重复导出沿用相同随机记录编号；老师以该编号合并同一学生多次记录，以最近一次为准。不要把这段记录公开发到群聊。

**未通关也可以导出。**建议课后全部学生都提交，包括中途停下的学生，才能看出哪里最容易卡住。导出前若出现“另一标签已更新”，先刷新当前页面。

## 教师收集与分析

- 收集学生私下发送的 CSV 文件或复制文本，集中上传给我即可。我可按班级和题目统计：完成率、各题正式尝试次数、曾答错比例、变式重练次数、仍未掌握比例、自评最难部分与整局活动时长。
- CSV 为 UTF-8（含 Excel 识别用标记），**每局 14 行，一题一行，18 列**；其中班级、总分、整局活动秒数等会在 14 行重复，统计学生人数或总用时时要先按随机记录编号去重，不能把 14 行的活动秒数相加。
- 复制的 JSON 与 CSV 含相同的教学指标；CSV 和 JSON 均不包含姓名、学号、训练编号、答案、精确完成时间或 IP。随机记录编号只用于合并同一局的多次导出。由于包含班级和逐题学习轨迹，仍属于可能间接识别个人的教学数据，建议定向收集、限制传播。
- 页面不会自动向 GitHub 或老师服务器上传。**老师只有收到学生发来的文件或文本，才能统计**。此前约四个班的数据，只有学生还保留原网址同一浏览器的 V2.4 本机记录，才能通过 V2.5 导出；不存在从 GitHub Pages 追溯下载所有人的记录的功能。
- 本地分数和时间可由设备持有人修改，这份数据适合改进教学设计，不是防篡改考试凭证。活动时长为页面可见学习时段，不等于自然历时，也没有逐题用时。

版本：**V2.5，2026-11-05**。新增可复制 JSON、可下载 CSV、可选难点反馈与 V2.4 存档迁移；保留四关 14 题、100 分、关尾必修错题重练、身份锁定、宠物反馈和一页打印成绩单。新版使用 `alkane-four-v2_5` 存档；首次迁移只读取并保留 V2.4 存档，既往已通关的 V2.4 成绩锁继续按原版记录核对。
