# 烷烃四关通关游戏 V2.9 · 实验提示修复版

## 上传到原 GitHub Pages 仓库

1. 解压 ZIP，把其中 **9 个文件**全部上传到原仓库顶层，覆盖同名文件。顶层直接包含 `index.html`、`service-worker.js`、`manifest.webmanifest`、四个图标、`.nojekyll` 和本说明。
2. 等待 `Settings → Pages` 部署完成。用原网址打开，确认页面显示 **V2.9**；网址不变，原二维码仍可使用。
3. 学生沿用原设备和浏览器重新打开并刷新；旧离线缓存更新后显示新版。

独立 HTML 可直接离线打开；GitHub Pages 请上传 ZIP 内全部文件。不要把学生名单、学号或导出的学习记录上传到公开仓库。

## V2.9 修复

第四关第 1、3 题的 A、B 两组已运行且符合单变量对照时，实时提示会说“已形成单变量对照，请比较观察结果”，不再错误地说“两组受光条件相同”或“两组用量相同”。未形成有效对照时，提示继续指明需固定或改变的条件；只有对应组条件被改变时才需重新运行该组。结论与依据的选项和判分规则沿用 V2.8，本次未修改题目答案。

V2.4—V2.8 的同设备同浏览器进度及已锁定成绩可迁移，旧存档保留。进行中的任务从未完成处继续；错题仍需在每关关尾完成变式重练，完成前不能打印成绩单。V2.8 导出的随机记录编号沿用；新记录的详细覆盖范围为 `full-v2.9`，升级自 V2.8 的记录为 `from-v2.8`，此前已采集的事件保留。
